🔐 Authentication UI App

Authentication UI App is a React Native Expo application that demonstrates login and signup workflows without relying on a database or backend. The project focuses on building a clean and user-friendly authentication experience with form validation, password handling, navigation, and structured login and registration screens.

✨ Key Features

* 🔐 Login screen
* 📝 User registration screen
* ✅ Form validation
* 🔑 Password input and handling
* 👁️ Password visibility controls
* ⚠️ Input error handling
* 🧭 Navigation between authentication screens
* 🚫 No database dependency
* 🚫 No backend required
* 📱 Clean and responsive React Native UI
* 🎯 User-friendly authentication workflow
* 🔄 Form state management

🏗️ Architecture & Workflow

The application focuses on the frontend authentication workflow, where users can navigate between login and registration screens and enter their credentials through validated forms. Input fields provide validation and error feedback to improve the user experience, while navigation manages the transition between authentication-related screens.

Since the project does not use a backend or database, authentication functionality is implemented purely as a UI and workflow demonstration rather than a production authentication system.

🛠️ Tech Stack

React Native • Expo • JavaScript • React Navigation • Form Validation • State Management • Responsive UI

▶️ Run the App

1. Install dependencies

npm install

2. Start Expo

npx expo start

3. Run on Android

npx expo start --android

4. Run on iOS

npx expo start --ios

5. Run on Web

npx expo start --web

🎯 Project Purpose

This project demonstrates how to create a clean authentication interface in React Native and Expo without backend complexity. It provides practical experience with form validation, password handling, navigation, input states, error handling, and designing user-friendly login and registration workflows.
